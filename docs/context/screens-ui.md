# Screens & UI

**Mini player**:
Bottom bar on small screens showing current song, play/pause, and skip. Tapping opens the full player.
_Avoid_: now playing bar, bottom player

**Sidebar player**:
Player widget in the left sidebar on large screens (tablet/TV). Shows artwork, controls, and library toggle.
_Avoid_: side player, panel player

**Full player**:
Full-screen player with artwork, controls, queue access, and sleep timer. Opened from mini player or sidebar.
_Avoid_: player screen, expanded player

**Library screen**:
Screen with two tabs: Songs (Library playlist) and Playlists (user playlists + Recent Songs).
_Avoid_: home, main screen

**Search screen**:
Screen for finding songs and albums online via API.
_Avoid_: discover, browse

**Queue screen**:
Screen showing the current playback queue with reorder and remove capabilities.
_Avoid_: up next screen

**Album detail screen**:
Screen showing album artwork, metadata, and song list. Tapping a song plays the full album.
_Avoid_: album view, album page

**Settings screen**:
Screen for app configuration.
_Avoid_: preferences, options
