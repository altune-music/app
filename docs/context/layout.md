# Layout

**Small screen**:
Devices with limited width (phones). Shows mini player at bottom.
_Avoid_: mobile, phone

**Large screen**:
Devices with wider display (tablets, TV). Shows sidebar with navigation and player.
_Avoid_: tablet, desktop

**Sidebar**:
Left panel on large screens containing navigation links and the sidebar player.
_Avoid_: nav panel, drawer

**Content panel**:
Right panel on large screens showing the selected section.
_Avoid_: main area, body
