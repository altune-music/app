# Controls

**Shuffle**:
Randomize the order of upcoming songs in the queue. Toggle on/off.
_Avoid_: random, mix

**Repeat off**:
Playback stops at end of queue.
_Avoid_: no repeat

**Repeat all**:
Playback restarts from beginning of queue when it ends.
_Avoid_: repeat queue

**Repeat one**:
Current song repeats when it finishes.
_Avoid_: repeat track, single repeat

**Sleep timer**:
Timer that pauses playback after a set duration (15, 30, 45, 60, or 90 minutes).
_Avoid_: auto-stop, snooze
