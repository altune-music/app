# Actions

**Play Next**:
Insert a song into the queue immediately after the current song.
_Avoid_: play next up

**Add to Queue**:
Append a song to the end of the queue.
_Avoid_: queue song, enqueue

**Add to Library**:
Add a song to the Library system playlist. Automatically saves for offline playback.
_Avoid_: save, pin, download

**Remove from Library**:
Remove a song from the Library system playlist. Deletes local file only if song is in no other playlist.
_Avoid_: unsave, unpin

**Add to Playlist**:
Add a song to a user playlist. Automatically saves for offline if not already available.
_Avoid_: save to playlist
