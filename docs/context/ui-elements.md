# UI Elements

**Bullet separator**:
The "•" character used between year and artist in album/search metadata (e.g., "2024 • Artist Name").
_Avoid_: dot separator, middle dot

**Explicit content badge**:
Visual badge displayed below the album artist line indicating the album contains explicit content.
_Avoid_: explicit indicator, content warning

**Playlist picker**:
Bottom sheet showing available playlists for adding a song. System playlists (Library, Recent Songs) are hidden from the picker.
_Avoid_: playlist selector, add to playlist sheet
