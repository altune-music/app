# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it
privately rather than opening a public issue.

You can report it by:

* Opening a **private security advisory** on GitHub.
* Contacting the maintainer directly.

Please include a clear description of the issue, steps to reproduce, and any
relevant details.

Do not report security issues through public issues, discussions, or pull
requests.
