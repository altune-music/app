# Contributing to altune

## Setup

1. Clone the repository.
2. Run `flutter pub get`.
3. Run `flutter test`.

See [`AGENTS.md`](AGENTS.md) for workflow and conventions.

## Guidelines

- Read the relevant spec in [`docs/specs/`](docs/specs) before changing behavior.
- Write or update tests with every change.
- Run `dart format .`, `flutter analyze`, and `flutter test` before submitting.
- Keep changes focused and minimal.
- Update specs when behavior changes.
- Link related issues in your PR.

Questions or ideas? Open an issue first.
